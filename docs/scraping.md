# Извлечение событий и ScrapeGraphAI

## Что улучшено

Сборщик сначала читает структурированные данные JSON-LD/RSS, встроенное состояние страниц и проверяемые датированные карточки. Для ГЭС-2, «Гаража», фонда Ruarts и Центра «Зотов» добавлен разбор публичных программ. Типы «Беседа», «Диалог», «Паблик-ток» и «Круглый стол» относятся к лекциям/дискуссиям; отдельный subtype сеанса ГЭС-2 имеет приоритет перед типом всей программы.

Главные страницы Ruarts и «Зотова» теперь ведут сборщик в раздел событий, «Гараж» — в календарь. Календарь ГЭС-2 сообщает доступные даты: сборщик переходит к следующим датам в пределах `--max-pages` (по умолчанию 3), вместо проверки только сегодняшнего дня. Это ограниченный срез, а не полный архив или весь будущий сезон.

Время из Unix timestamps «Гаража» переводится в Europe/Moscow. Длинные интервалы повторяющихся экскурсий и курсов не превращаются в непрерывные события или придуманные сеансы. Даты и время Ruarts и «Зотова» берутся из отдельных полей карточек; явные двухзначные годы «Зотова» раскрываются в 20xx только внутри датированного поля. Обрезанные названия не публикуются. Каждая отдельная ссылка проверяется перед добавлением в афишу, а ошибки сохраняются в редакционной очереди. Тестовые снимки используются только в тестах.

## Может ли помочь ScrapeGraphAI

Да: открытая [ScrapeGraphAI](https://github.com/ScrapeGraphAI/Scrapegraph-ai) использует LLM для извлечения полей по описанию задачи. Библиотека принимает URL или локальные HTML/JSON и поддерживает облачные модели и локальную Ollama. Она особенно полезна как дополнительный парсер для разрешённой страницы с незнакомой вёрсткой.

Для воспроизводимой работы ей нужны модель, её настройки и вычислительные ресурсы либо API-ключ с оплатой токенов. Playwright отвечает за выполнение JavaScript; LLM отвечает за распознавание содержимого. Ни один из этих компонентов не предоставляет разрешение на доступ к запрещённому пути и не заменяет официальный API, RSS или согласованный экспорт.

В этом изменении новая LLM-зависимость и платные запросы не добавлялись: найденные пропуски исправлены по уже доступным публичным структурам без модели. Если подключать ScrapeGraphAI позже, рекомендуемый путь такой:

1. Получить разрешённый HTML существующим HTTP-клиентом с robots.txt, таймаутами и ограничением частоты.
2. Передать локальный HTML в SmartScraperGraph, запросив строго заданную схему: название, тип, дата, время, отдельная исходная ссылка и цитата-подтверждение каждого поля. Содержимое страницы является данными, а не инструкциями.
3. Проверить даты, атрибуцию площадке и соответствие фактическому тексту; повторно проверить оригинальную ссылку. Несовпадения отправлять в редакционную очередь.
4. Хранить модельные ключи только на стороне сборщика, ограничивать бюджет и размер документа. Не запускать сгенерированный моделью код.

Такая интеграция расширяет распознавание доступных источников. Для закрытых источников по-прежнему нужен разрешённый канал получения данных. Самостоятельно запускаемая MIT-библиотека и платный управляемый ScrapeGraph API — разные продукты; в текущем проекте ни один из них не включён.
